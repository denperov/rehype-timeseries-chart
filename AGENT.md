# rehype-timeseries-chart Project

This repository contains a rehype plugin written in TypeScript. Node.js 18 or higher is required.

## Build & Commands

- Install dependencies: `npm install`
- Run the test suite: `npm test`
- Build the library: `npm run build`
- Format files: `npx prettier -w <files>`

## Code Style

- Strict TypeScript with `exactOptionalPropertyTypes`
- Single quotes, trailing commas, and no semicolons
- Prefer descriptive variable names
- Document public APIs with JSDoc
- 100 character line limit

## Git Workflow

- Format changed files with Prettier before committing
- Always run `npm test` and ensure the build succeeds
- Keep commits focused and avoid force pushing to main
